# How to open your CVs

GitHub PR **"could not parse diff"** is normal for PDF files — GitHub cannot preview binary PDFs in the diff view.

## Easiest options

### 1. Download from Artifacts (best)
Download these files from the agent artifacts panel:
- `Samuli-Lahtela-CV-Affiliate-Executive.pdf` ← **use for Affiliate Executive**
- `Samuli-Lahtela-CV-Casino-Operations-Limassol.pdf`
- `Samuli-Lahtela-CV.pdf` (VIP/CRM)
- `Samuli-Lahtela-CVs.zip` (all PDFs + HTML)

### 2. Open HTML in browser → Save as PDF
Open any file in `career/html/`:
1. Open the `.html` file in Chrome/Edge
2. Press **Ctrl+P** (Print)
3. Destination: **Save as PDF**
4. Margins: Default, Background graphics: On

### 3. Download from GitHub (not the Diff tab)
1. Open the PR → **Files changed**
2. Click the **PDF filename** (not the red/green diff)
3. Click **View raw** or **Download**
4. Or go to the branch → `career/` folder → click PDF → Download

**Do not** try to open PDFs inside the PR "diff" view — that is what causes "could not parse diff".
